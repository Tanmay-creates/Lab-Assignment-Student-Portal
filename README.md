# Student Portal

A simple Student Portal webpage built with HTML and CSS as part of a lab assignment on HTML structure and introductory CSS.

## Overview

The page simulates a basic college student portal where a student can:

- View their profile
- See their list of skills
- Check their weekly class schedule
- Register for a course

## Features

- Semantic HTML structure (`header`, `nav`, `main`, `section`, `footer`)
- Navigation menu
- Student profile displayed in a table
- Skills list (unordered list)
- Weekly class schedule table
- Course registration form with:
  - Text and email inputs
  - Dropdown course selection
  - Radio buttons (learning mode)
  - Checkboxes (known skills)
  - Submit and reset buttons
- CSS styling including:
  - Text and background colors
  - Element, class, and ID selectors
  - Centered, larger layout

## Files

- `student-portal.html` — the complete webpage (HTML + CSS in one file)

## Tech Used

- HTML5
- CSS3 (no frameworks, no JavaScript)
